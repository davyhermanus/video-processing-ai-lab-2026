# Upload to GitHub using the browser

Repository: https://github.com/davyhermanus/video-processing-ai-lab-2026

1. Extract this ZIP on your computer.
2. Open the repository. If empty, choose **uploading an existing file**; otherwise choose **Add file → Upload files**.
3. Drag the **contents** of this extracted folder (not the enclosing folder or ZIP) into the upload area. Keep the directories as shown.
4. Wait for uploads; the largest individual source video is around 20 MB.
5. Enter commit message `Add Session 07 complete lab materials` and click **Commit changes**.
6. Refresh the repository and check `README.md`, `notebooks/`, and `source/` and `results/`.
7. Test an **Open in Colab** link from the README.

If drag-and-drop folder upload is not supported by your browser, use GitHub Desktop to **Add existing repository** / Clone your empty repository and copy these files into it, then commit and push.

IMPORTANT: Check video redistribution rights and personal privacy before uploading videos into a PUBLIC repository.
